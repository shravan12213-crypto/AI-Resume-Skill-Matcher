# Development Phases

**Development Order is Extremely Important. Do NOT start by building the UI.**

1. **Phase 1: Planning / Database Design** (Currently In Progress)
   - Problem statement, actors, requirements, entities, relationships.
2. **Phase 2: ER Diagram + Relational Schema**
   - See `phase-2-database-design.md` for exact sequence.
3. **Phase 3: PostgreSQL Implementation**
   - Tables, constraints, seed data, basic queries.
4. **Phase 4: Core Application**
   - Candidate, Recruiter, Jobs, Applications, Resume repository.
5. **Phase 5: DBMS Features**
   - Complex queries, views, procedures, functions, triggers, transactions, indexes, EXPLAIN ANALYZE, roles.
6. **Phase 6: SQL Matching**
   - Match calculation, ranking, matched/missing skills.
7. **Phase 7: AI Integration**
   - Resume upload, extraction, OpenAI API, insert into DB.
8. **Phase 8: Integration + Polish**
   - Connect all parts, testing, UI polish, deployment.\n
