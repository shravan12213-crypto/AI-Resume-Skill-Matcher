# Functional Requirements

## Candidate Module
- Register/login and manage profile.
- Upload resume to the repository.
- View extracted information and skills.
- Edit profile information where appropriate.
- View available jobs and apply to them.
- View application status.

## Recruiter Module
- Register/login and manage company/recruiter profile.
- Create jobs with required skills and experience.
- View applications and search/filter candidates.
- View candidate profiles and extracted skills.
- View candidate-job match scores (matched/missing skills).
- Rank candidates.

## AI Module
- Accept resume upload.
- Extract text (PDF/DOCX).
- Pass text to OpenAI API.
- Return structured JSON (skills, education, experience, etc.).
- Insert structured data into PostgreSQL.\n
