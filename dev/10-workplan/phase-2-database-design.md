# Phase 2 Preparation: ER Diagram + Relational Schema

**Do not implement SQL tables yet.**

Complete this sequence during Phase 2:
1. Identify final entities
2. Identify attributes
3. Identify candidate keys
4. Select primary keys (Integer based)
5. Identify foreign keys
6. Identify 1:1 relationships
7. Identify 1:N relationships
8. Identify M:N relationships
9. Identify associative entities (Composite PKs)
10. Define cardinalities
11. Create ER diagram
12. Convert ER model to relational schema
13. Check normalization (up to 3NF)
14. Validate schema against requirements
15. Review with both team members
