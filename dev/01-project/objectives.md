# Objectives

1. Design and implement a robust, normalized relational database up to 3NF.
2. Demonstrate advanced DBMS concepts including views, stored procedures, functions, triggers, and transactions.
3. Optimize database queries using indexing and `EXPLAIN ANALYZE`.
4. Implement a clear, explainable SQL-based skill matching engine.
5. Create a secure, role-based access control system using PostgreSQL roles.
6. Integrate AI purely as an input-processing tool to feed structured data into the database.\n
